      Questions

      Good to know.

      Does it need internet?

      No. The app works fully offline and the release version does not request internet access.

      Where is my data stored?

      In a database on your phone. There is no account and no server, so we never see it.

      How do I move to a new phone?

      Make a backup file from the More tab, send it to yourself, and restore it on the new phone.

      Does it convert currencies?

      No. The currency you choose changes the symbol and how numbers are grouped. Amounts are never converted.

      Is there an iPhone version?

      Not at the moment. Hisaab Kitaab is built for Android.
